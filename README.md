#EU translate

Practical Assignment 01. Variant B.

Task Description.
The materials manager enters the stock level (S) and daily consumption (D); the application displays the number of full days (S / D) and the remainder (S % D).

Environment Settings.
- Android Studio
- Gradle 8.0
- Android Gradle Plugin 8.0.2
- Java 17 (JetBrains Runtime 17.0.6)
- minSdk 24, targetSdk 34, compileSdk 34
- Pixel 6 Emulator API 34

Launch.
1. Open the project in Android Studio.
2. Run the `app` configuration on an emulator or a physical device.
3. Enter integers between 1 and 1000 into both fields.
4. Tap "Calculate" — the result will appear, including units of measurement.
5. The "Clear" button resets the input fields, error messages, and the result.

Not implemented.
- State is not preserved after a restart (not required by the assignment).
- No support for negative numbers or zero (range is 1–1000).
- There are no connections to databases or third-party libraries.


#RU translate

Практическое задание №1. Вариант B.

Описание задачи.
Менеджер по учету материалов вводит текущий запас (S) и суточный расход (D); приложение отображает количество полных дней (S / D) и остаток (S % D).

Настройки среды.
- Android Studio
- Gradle 8.0
- Android Gradle Plugin 8.0.2
- Java 17 (JetBrains Runtime 17.0.6)
- minSdk 24, targetSdk 34, compileSdk 34
- Эмулятор Pixel 6 (API 34)

Запуск.
1. Откройте проект в Android Studio.
2. Запустите конфигурацию `app` на эмуляторе или физическом устройстве.
3. Введите целые числа в диапазоне от 1 до 1000 в оба поля.
4. Нажмите кнопку «Рассчитать» (Calculate) — отобразится результат, включая единицы измерения.
5. Кнопка «Очистить» (Clear) сбрасывает поля ввода, сообщения об ошибках и результат.

Не реализовано.
- Состояние не сохраняется после перезапуска.
- Нет поддержки отрицательных чисел или нуля (диапазон: 1–1000).
- Отсутствуют подключения к базам данных или сторонним библиотекам.
